# 🚀 Partners HUB AI Voice Agent — Deploy Guide

## Aapko milenge 3 files:
1. partnershub_voice_agent.py  (main code)
2. requirements.txt            (libraries)
3. Procfile                    (server config)

═══════════════════════════════════════════════
## STEP 1: GitHub Account Banao (Free)
═══════════════════════════════════════════════

1. https://github.com par jaao
2. Sign up karo (email se)
3. New Repository banao — naam: "partnershub-agent"
4. Public rakho
5. Teeno files upload karo

═══════════════════════════════════════════════
## STEP 2: Railway.app par Deploy Karo (Free)
═══════════════════════════════════════════════

1. https://railway.app par jaao
2. "Start a New Project" click karo
3. GitHub se login karo
4. "Deploy from GitHub repo" select karo
5. Aapka "partnershub-agent" repo select karo
6. Deploy ho jayega — 2-3 minute mein

## STEP 5: Twilio Mein URL Set Karo
═══════════════════════════════════════════════

Twilio Console mein jaao:
Phone Numbers → Verified Caller IDs

Ya naya number kharido:
Phone Numbers → Buy a Number

Number ki settings mein:
Voice & Fax → "A Call Comes In" section:
URL daalo: https://[aapka-railway-url]/voice
Method: HTTP POST

## SYSTEM KAISE KAAM KAREGA
═══════════════════════════════════════════════

1. Aap "Morning Calls" button dabao
2. System agent ko call karega (Twilio)
3. Agent uthayega → AI bolega:
   "Namaskar [Agent Ji]! Main PB Partner ke
    Prashant Ji ki team bol raha hoon..."
4. Agent apni problem bolega
5. AI samjhega aur jawab dega (OpenAI)
6. Agar agent fase → AI bolega:
   "Main aapko Prashant Ji se connect karta hoon"
7. Call aapke (+917709446589) par transfer!
